# Security Policy

## Supported Versions

Only the current development version (`master` branch) is supported. There are no releases yet.

Versions of the original eDEX-UI (up to v2.2.8) are unmaintained and have known security issues; please don't use them.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub: [report a vulnerability](https://github.com/adamsjoe/neodex-ui/security/advisories/new). Don't open a public issue for security problems.

Include what you think is vulnerable and, if possible, how to reproduce it.
